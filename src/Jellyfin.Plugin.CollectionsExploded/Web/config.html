Show a separate horizontal row of media for each collection containing the item.
Default: 20. Allowed range: 1–100. This limits each row; every accessible collection still gets a row.
Sorting is applied before the item limit. Date added is the media item's library date. Unknown years follow Jellyfin's normal ordering.

Settings apply to all users of the server-hosted Jellyfin web client. Reopen or refresh a media detail page to apply saved changes.

Requires Jellyfin 12 or newer and File Transformation 3 or newer.
